# Legacy Materials

This folder holds archived material that should not be used as the starting point for new app work.

## Contents

- `open-camera-embedded-prototype/` - the side-project prototype that proved embedded Open Camera could work.
- `external-open-camera-apk/` - the old standalone Open Camera APK dependency from the external-camera workflow.

## Current Main Version

Use `../android-app/` for all future development. The main app already embeds Open Camera as a source module and builds through `../scripts/build-android.ps1`.
